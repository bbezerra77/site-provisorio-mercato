# 🌿 Mercato Jardim — O Sabor do que é Verdadeiro

> Website institucional premium e interativo para o **Mercato Jardim**, o primeiro supermercado de bairro gastronômico e *pet friendly* de São Paulo.

🔗 **Acesse o site online:** [https://bbezerra77.github.io/site-provisorio-mercato/](https://bbezerra77.github.io/site-provisorio-mercato/)

---

## ✨ Destaques & Funcionalidades

* 🏛️ **Design Gastronômico Premium**: Visual imersivo em modo escuro (*dark luxury*), com tipografia sofisticada (*Cormorant Garamond* e *Inter*), micro-interações e detalhes refinados.
* 🖱️ **Vitrine Interativa com Troca de Imagens no Hover**: Ao passar o cursor pelas tags de cada setor, a imagem principal se transforma suavemente para exibir o produto selecionado:
  * **Frutas & Exóticas**: Limão Siciliano, Pitaya, Manga, Uvas Importadas, Morangos Selecionados e Figos.
  * **Padaria Artesanal**: Pão Sourdough, Croissant Amanteigado, Ciabatta Rústica, Baguete Francesa Tradicional, Confeitaria Fina e Pão de Queijo Mineiro.
  * **Hortifruti Orgânico**: Ervas Frescas, Pimentões Selecionados, Tomates Heirloom, Brócolis Fresco, Alho Nobre e Couve Kale.
  * **Mercearia & Bebidas**: Azeite Extra Virgem, Vinhos Selecionados, Massas Artesanais, Conservas Finas, Sal Rosa do Himalaia e Cafés Especiais.
* 🌀 **Transição Teleport**: Efeito cinematográfico com partículas douradas e barra de carregamento estético ao navegar diretamente para os setores.
* 🎯 **Cursor Dinâmico & Parallax**: Cursor customizado que reage aos links e elementos clicáveis, com efeitos suaves de profundidade e rolagem.
* 📱 **100% Responsivo**: Experiência fluida e adaptada para dispositivos móveis, tablets e telas widescreen.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estrutura semântica e acessível.
* **CSS3**: Layout moderno com CSS Grid, Flexbox, variáveis personalizadas e animações com keyframes.
* **JavaScript (Vanilla)**: Lógica reativa sem frameworks pesados, garantindo performance ultra rápida de carregamento.
* **GitHub Pages**: Hospedagem contínua e distribuição global.

## 💻 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/bbezerra77/site-provisorio-mercato.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd site-provisorio-mercato
   ```
3. Abra o arquivo `index.html` em qualquer navegador ou use um servidor local:
   ```bash
   npx serve .
   ```
